TASK 7

The lightbulb: onload(), onmouseover(), onmouseout()

Move your mouse over the bulb to turn it on and move away to turn it off.

Annotations

The image starts with off.png, so the bulb is off when the page loads. The onmouseover event calls Bulbon() when the mouse moves over the image. This function uses document.getElementById("lightbulb") to find the image and changes its src to onn.png. The onmouseout event calls Bulboff() when the mouse leaves, changing the image back to off.png. Clicking the image calls Big(), which increases its width by 15 pixels each time. When its width becomes greater than 300 pixels, it resets to 150 pixels.
